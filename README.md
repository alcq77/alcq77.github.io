# 知行笔记

记录学习和实践中的方法、命令与排障经验，方便回查，也分享给遇到类似问题的人。

**在线阅读：[知行笔记](https://alcq77.github.io/)**

## 内容

- **Linux**：常用命令、系统状态、服务管理、开机自启、内核与性能排查。
- **Nginx**：配置项、静态网站、反向代理、HTTPS、日志排障和配置发布。
- **Docker 与 Compose**：容器、镜像、网络、数据卷及日常维护。
- **Kubernetes**：应用部署、配置管理、集群维护与故障排查。
- **Kafka**：部署运维、消息可靠性、消费积压及核心机制。

内容会根据使用中遇到的问题持续补充和修正。

## 阅读与使用

建议直接在网站阅读，可以按关键词搜索、通过文章目录定位内容，也可以复制命令和配置示例。

笔记中的版本、路径、端口和服务名需要按实际环境调整。执行修改、删除或重启等操作前，先确认影响范围并做好相应备份。

本仓库保存网站的公开页面与相关资源，阅读入口以上方网站链接为准。
